# Pit Wall Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A top-down 2D incremental racing game: the player's team races AI rivals on spline circuits, earns money per lap, overtake and finish, buys upgrades and cars, and unlocks harder circuits with reputation.

**Architecture:** Pure, Node-tested modules hold all rules (`config`, `format`, `track`, `car`, `race`, `economy`, `save`, `view`). Browser modules draw and wire it (`render/background`, `render/scene`, `ui`, `main`). Simulation runs on a fixed 1/120 s step; rendering every animation frame. Only the player profile is saved.

**Tech Stack:** Vanilla JavaScript ES modules, Canvas 2D, localStorage, Node 20 `node:test`.

**Spec:** `docs/design.md`

## Global Constraints

- No build step, no dependencies: `package.json` is exactly `{"name":"pit-wall","private":true,"type":"module","scripts":{"test":"node --test"}}`.
- Tests: `node:test` + `node:assert/strict`, `npm test`, files `tests/*.test.js`, Node 20.
- Pure modules (everything except `src/render/*`, `src/ui.js`, `src/main.js`) never touch `document`, `window`, `localStorage` or `performance`.
- Browser code loads with `<script type="module">`; every path is relative (GitHub Pages serves under `/racing-incremental/`).
- All constants live in `src/config.js`; other modules import them, never redefine them.
- World coordinates: 1600 × 1000 units, y pointing down. The view scales the world to the canvas.
- UI copy in French. No emojis in code or copy.
- Commit messages: subject, blank line, `Co-Authored-By: Claude <model> <noreply@anthropic.com>` naming the model that wrote the commit.

## Review Focus

1. Cars must never visibly overlap or drive through each other, including a leader lapping a backmarker (gap computed modulo track length). Test: Task 4 `no pass-through while overtaking`.
2. Cars must slow down before corners instead of exceeding the corner speed. Test: Task 3 `lone car respects corner speeds`.
3. Overtake money must not be farmable by losing and regaining a place. Test: Task 4 `overtakes pay only for new best ranks`.
4. A corrupt save or blocked storage must start a fresh game instead of crashing; a NaN money must never be written. Test: Task 6.
5. Every circuit must be drivable: closed, no self-intersection, no corner tighter than radius 45, inside the world. Test: Task 2 `all circuits are valid`.

### Task 2: Track geometry

**Files:** Create `src/track.js`, `tests/track.test.js`. May modify `TRACKS[i].points` in `src/config.js`.

**Interfaces:**
- Consumes: `TRACK_WIDTH`, `TRACK_STEP`, `WORLD`, `TRACKS`.
- Produces:
  - `buildTrack(def) -> Track` where `Track = { def, width, step, length, count, xs, ys, headings, curvs }` (`xs…curvs` are `Float64Array` of `count` resampled points spaced `step` apart along the centerline, closed loop: point `count` would coincide with point 0).
  - `sampleAt(track, s) -> { x, y, heading }` — `s` in any range (wraps modulo length, negatives allowed), linear interpolation between neighbours, heading interpolated along the shortest angle.
  - `curvAt(track, s) -> number` — signed curvature at the nearest sample (1/units; positive = turning toward the normal `(-sin h, cos h)`).
  - `pointAt(track, s, lateral) -> { x, y, heading }` — `sampleAt` offset by `lateral` along the normal `(-sin h, cos h)`.

**Algorithm (`buildTrack`):**
1. Closed centripetal Catmull-Rom (alpha 0.5) through `def.points`; sample each span densely (40 sub-steps).
2. Cumulative length over the dense polyline; resample at exact multiples of `TRACK_STEP`; `length` = total length, `count = Math.floor(length / step)`, then set `step = length / count` so the loop closes exactly.
3. `headings[i] = atan2(y[i+1] − y[i−1], x[i+1] − x[i−1])` (indices wrap).
4. Raw curvature `k[i] = wrapAngle(headings[i+1] − headings[i−1]) / (2·step)`; `curvs` = circular moving average of `k` over 7 samples.

### Task 3: Car speed physics

**Files:** Create `src/car.js`, `tests/car.test.js`.

**Interfaces:**
- Consumes: `NITRO`, `BASE_CAR`, `TRACKS`; `buildTrack`, `curvAt`.
- Produces (params objects are `{ topSpeed, accel, brake, grip }`):
  - `cornerSpeed(curvature, grip) -> number` — `Infinity` when `|c| < 1e-6`, else `Math.sqrt(grip / |c|)`.
  - `targetSpeed(track, s, params) -> number` — `min(topSpeed, min over d = 0, 8, 16, … ≤ lookahead of sqrt(cornerSpeed(curvAt(track, s + d), grip)² + 2·brake·d))` with `lookahead = topSpeed² / (2·brake) + 16`.
  - `nextSpeed(v, target, params, dt) -> number` — below target: `min(target, v + accel·(1 − 0.6·v/topSpeed)·dt)`; otherwise `max(target, v − brake·dt)`.
  - `effectiveParams(params, nitroActive) -> params` — when active, `topSpeed × NITRO.speedMult` and `accel × NITRO.accelMult`; otherwise the same values (new object either way).

### Task 4: Race manager

**Files:** Create `src/race.js`, `tests/race.test.js`.

**Interfaces:**
- Consumes: `LAPS`, `RACE`, `CAR_LENGTH`, `CAR_WIDTH`, `TRACK_WIDTH`; `curvAt`; `targetSpeed`, `nextSpeed`, `effectiveParams`.
- Produces:
  - `createRace(track, entrants, rng = Math.random) -> Race`. `entrants: [{ id, teamId, own, label, params }]`. `Race = { track, time, phase: 'countdown' | 'racing' | 'finished', cars, finishOrder: [], firstFinishTime: null, results: null }`; `time` starts at `−RACE.countdown`. Each car = entrant fields + `{ s, lateral, latTarget, v: 0, laps: 0, finished: false, nitroUntil: -Infinity, nitroReadyAt: 0, bestRank, braking: false }`. Grid: shuffle entrants with `rng` (Fisher–Yates); slot `i` gets `s = −RACE.gridGap·(i + 1)`, `lateral = latTarget = (i % 2 ? 1 : −1) · 0.3 · TRACK_WIDTH/2`; `bestRank` = initial rank (1-based).
  - `trackGap(from, to, length) -> number` — signed shortest distance from car `from` to car `to` along the loop: `((to.s − from.s) mod length + length) mod length`, minus `length` if above `length/2`.
  - `standings(race) -> Car[]` — finished cars in `finishOrder`, then the rest by `s` descending.
  - `stepRace(race, dt) -> Event[]` (see algorithm). Events: `{ type: 'lap', carId, lap }`, `{ type: 'overtake', carId, count }`, `{ type: 'finish', carId, position }`, `{ type: 'raceEnd', results: carId[] }`.
  - `tryNitro(race, carId, nitro: { duration, cooldown }) -> boolean` — false unless phase is 'racing' and `race.time ≥ car.nitroReadyAt`; then `nitroUntil = time + duration`, `nitroReadyAt = time + cooldown`.
  - `overtakeGains(cars, order) -> Array<{ carId, count }>` — for each own, unfinished car whose 1-based rank in `order` is below its `bestRank`: gain `bestRank − rank`, update `bestRank`. Pure, exported for tests.

**`stepRace` algorithm:**
```
if phase == 'finished': return []
time += dt
if phase == 'countdown': if time >= 0: phase = 'racing'; return []
half = TRACK_WIDTH/2; L = track.length; maxLat = half − CAR_WIDTH/2 − 3
for car in cars sorted by s descending (leader first, so the car ahead has already moved):
  p = effectiveParams(car.params, time < car.nitroUntil)
  free = targetSpeed(track, car.s, p); target = free
  ahead = nearest other car with 0 < trackGap(car, other, L) < 60 and |other.lateral − car.lateral| < CAR_WIDTH + 4
  if ahead:
    if trackGap(car, ahead, L) < CAR_LENGTH + 8: target = min(target, ahead.v)
    if free > ahead.v + 5: car.latTarget = (ahead.lateral > 0 ? −0.55 : 0.55) · half
  else if no other car has |trackGap(car, other, L)| < 80: car.latTarget = 0
  car.braking = target < car.v − 1
  car.v = nextSpeed(car.v, target, p, dt); car.s += car.v·dt
  if ahead and trackGap(car, ahead, L) < CAR_LENGTH + 2: car.s = ahead-relative position (CAR_LENGTH + 2 behind), car.v = min(car.v, ahead.v)
  lateral step: move toward latTarget by at most 45·dt; skip the move if, for any car with |trackGap| < CAR_LENGTH + 4, it would DECREASE |Δlateral| and leave it below CAR_WIDTH + 2 (moving away from a car is always allowed); clamp to ±maxLat
  laps = max(0, floor(car.s / L)); if laps > car.laps and not finished: car.laps = laps; emit lap
    if laps >= LAPS: finished = true; push finishOrder; firstFinishTime ??= time; emit finish {position: finishOrder.length}
order = standings(race); if time > RACE.overtakeGrace: emit overtakeGains(cars, order)
if all finished or (firstFinishTime !== null and time − firstFinishTime >= RACE.finishGrace):
  phase = 'finished'; results = standings ids; emit raceEnd
```
Finished cars keep driving (cool-down) and keep traffic rules.

  - `rivalParams(trackIndex, skill) -> params` — every `BASE_CAR` field × `(0.92 + 0.1·trackIndex) · skill`.
  - `lapReward(trackIndex)`, `overtakeReward(trackIndex, count)` — `LAP_REWARD · reward`, `OVERTAKE_REWARD · reward · count`.
  - `earn(profile, amount)` — adds to `money` and `stats.earned`.
  - `unlockedCount(profile) -> number` — number of tracks with `repRequired ≤ reputation`.
  - `settleRace(profile, results: carId[], ownIds: string[], trackIndex) -> { prize, reputation, unlocked: number | null }` — prize = Σ over own cars of `PRIZES[position − 1] · reward` (0 beyond the table), earned into the profile; reputation from the best own position (`REPUTATION[pos − 1] ?? 0`) added; `stats.races++`, `stats.wins++` when best is 1; if the unlocked count grew, `unlocked` = new highest index and `profile.trackIndex` = that index, else null.
